AIの安全性研究で知られるAnthropicが、セキュリティ脆弱性の発見を自動化するオープンソースフレームワーク「Defending Code Reference Harness」をGitHub上で公開しました。

このツールはClaudeなどのLLM（大規模言語モデル）を使って、ソフトウェアに潜むセキュリティ上の脆弱性を自動検出・分析してくれるものです。これまで熟練エンジニアが手作業でやっていたコード監査の一部をAIが担ってくれる、というイメージですね。

オープンソースなので誰でも無料で使えて改良もできます。セキュリティ研究者はもちろん、副業でコードレビューや脆弱性診断を請け負うフリーランスエンジニアにとっても、作業効率を大きく上げるツールになりそうです。セキュリティ診断は単価が高めの案件も多いので、このAIツールを使いこなせればより多くの仕事をこなせる可能性があります。

Anthropicがこうしたツールを積極公開する背景には、AI時代のセキュリティリスクに業界全体で向き合おうという姿勢がありそうです。AIが普及するほどソフトウェアの安全確認の重要性は増すばかり。このフレームワークが現場でどう活用されるか、注目したいところです。
